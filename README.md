# ⚡ ERT Data Analyzer & 2D Subsurface Modeler

أداة Python متكاملة لتحليل بيانات المسح الكهربائي للمقاومية (ERT)
والنمذجة ثنائية الأبعاد لباطن الأرض.

##  المميزات

- **قراءة البيانات**: دعم ملفات CSV مع تعليقات
- **فحص الجودة**: إحصاءات وصفية، فحص بنية الأقطاب
- **تنظيف تلقائي**: حذف القيم السالبة والصفرية والشاذة (IQR)
- **حساب المقاومية الظاهرية**: ρa = K × V/I لترتيب Wenner
- **Pseudosection احترافي**: مقطع ملون مستمر بمقياس لوغاريتمي
- **النمذجة الأمامية**: محاكاة 2D باستخدام pyGIMLi
- **الانعكاس ثنائي الأبعاد**: استنتاج النموذج الحقيقي من البيانات
- **واجهة ويب تفاعلية**: تطبيق Streamlit كامل
- **تصدير النتائج**: صور PNG بجودة 300 dpi
 

### المتطلبات
- Python 3.9 - 3.12
- pip (مدير حزم Python)
